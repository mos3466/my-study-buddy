# My Study Buddy — النسخة الأولى

موقع دراسي شخصي باللغة العربية باستخدام HTML وCSS وJavaScript فقط.

## التشغيل

1. فك ضغط الملف.
2. افتح `index.html` في المتصفح مباشرة.
3. أو من داخل المجلد شغّل `python -m http.server 8000` ثم افتح `http://localhost:8000`.

## الوظائف

- لوحة تحكم بمواعيد ومهام وإحصائيات.
- إضافة وتعديل وحذف الاختبارات والكويزات والتسليمات.
- إضافة مواد دراسية.
- تقويم شهري.
- مهام قابلة للتأشير وحفظ نسبة الإنجاز.
- خطة مذاكرة إرشادية بناءً على تاريخ الاختبار وعدد الفصول التقريبي.
- محادثة تجريبية تعتمد على قواعد بسيطة (ليست AI حقيقيًا)، تتعرف على تواريخ ISO وتطلب تأكيد الحفظ.
- حفظ محلي في localStorage.
- تذكير داخل الموقع عند فتحه؛ لا توجد إشعارات خارج المتصفح أو في الخلفية.

## ملاحظات

البيانات الأولية تجريبية ويمكن إعادة ضبطها من الإعدادات. لا يوجد خادم أو حسابات أو قاعدة بيانات سحابية في هذه النسخة. حفظ البيانات مرتبط بالمتصفح والجهاز، وقد تضيع عند مسح بيانات الموقع. استخدم تاريخ YYYY-MM-DD في المحادثة.
